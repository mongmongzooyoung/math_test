# 움직임의 미적분

고등학교 미적분 수업용 일차원 운동 실험 프로그램입니다. 위치함수를 입력하면 Math.js의 기호 미분으로 속도와 가속도를 계산하고, 세 그래프와 구슬 운동을 함께 보여줍니다.

## 실행

이 디렉터리에서 `python3 -m http.server 8000`을 실행한 후 브라우저로 접속하세요. Math.js 14.8.1을 CDN에서 로딩하므로 인터넷 연결이 필요합니다. 별도 설치나 API 키는 필요하지 않습니다.

- 예제: `t^3 - 6*t^2 + 9*t`, `3*sin(t)`, `2*t^2`
- 시간 구간 입력 → 계산 → 재생/일시정지, 시간 슬라이더, 배속 조절
- 위치 단위 m, 시간 단위 s, 삼각함수는 라디안
- 실수 범위에서 매끄러운 함수에 사용하세요. 그래프는 601개 표본으로 근사하며 표본 사이 불연속을 감지하지 못할 수 있습니다.
- 미분 결과와 적용 순서를 표시합니다. 개별 항의 상세한 미분 전개는 제공하지 않습니다.

## 확인

`node --check app.js`로 문법을 검사할 수 있습니다. 다항함수·삼각함수의 도함수, 초기 렌더링 및 잘못된 입력 처리를 검증했습니다.
